# Unemployment Analysis with Python

Exploratory data analysis of unemployment trends in India using Python, with a focus on regional differences, time-based trends, and the impact of the COVID-19 pandemic.

## Project Overview

This project analyzes unemployment data from India to understand how unemployment rates changed across different regions and over time.

The analysis focuses on regional unemployment differences, monthly trends, labour market indicators, and changes before and after the COVID-19 period.

## Objective

The main objectives of this project are:

- Analyze unemployment rates across different regions of India
- Study monthly and time-based unemployment trends
- Compare unemployment rates between major states/regions
- Identify states with higher average unemployment rates
- Study the relationship between unemployment rate, employment rate, and labour participation rate
- Compare unemployment conditions before and after the COVID-19 period

## Dataset

The project uses the **Unemployment in India** dataset containing information about unemployment and labour market indicators across different regions of India.

The dataset includes variables such as:

- Region
- Date
- Estimated Unemployment Rate (%)
- Estimated Employed
- Estimated Labour Participation Rate (%)

The project includes the following visualizations:

- Region-wise average unemployment rate
- Month-wise unemployment trend
- Time-series unemployment trends for major states/regions
- Top 10 states/regions with the highest average unemployment rate
- Correlation heatmap of unemployment rate, employment rate, and labour participation rate
- Pre-COVID vs Post-COVID comparison

## COVID-19 Analysis

The dataset is divided into pre-COVID and post-COVID periods to compare unemployment conditions.

The comparison helps identify changes in:

- Average unemployment rate
- Employment levels
- Labour participation rate

The analysis provides a data-based view of how unemployment conditions changed during the COVID-19 period.
